استمارات جامدة وتوهان للعميل

نماذج طويلة ومملة تسأل نفس الأسئلة لجميع أنواع المشاريع، مما يؤدي لمتطلبات ناقصة وغير مفهومة.

  • ⚠️ العميل لا يعرف المصطلحات التقنية فيكتب إجابات مبهمة مثل "أريد موقع ممتاز".
  • ⚠️ عشرات الاجتماعات ورسائل الواتساب للتوضيح وإعادة الاستفسار.
  • ⚠️ فريق التطوير يبدأ البرمجة بمتطلبات غير مكتملة، مما يسبب خلافات مالية وتأخيراً.
  • ⚠️ أي تعديل على الأسئلة يتطلب تدخلاً برمجياً لإعادة بناء النماذج.
✨ أسلوب Welco المبتكر والذكي

رحلة موجهة بالذكاء الاصطناعي مع تفرع منطقي

تجربة مستخدم ساحرة خطوة بخطوة تسأل فقط ما يخص المشروع، مع دعم فوري من Gemini لاقتراح الميزات.

  • ✅ الذكاء الاصطناعي يشرح للعميل خياراته ويقترح الميزات المتوافقة مع ميزانيته.
  • ✅ تفرع مسارات الأسئلة تلقائياً (متجر ➔ بوابات دفع، تطبيق ➔ متجر آبل وجوجل).
  • ✅ تسليم ملف متطلبات مهيكل ومعتمد رسمياً وقفل التعديلات قبل كتابة الكود.
  • ✅ المدير العام يتحكم في كل الأسئلة والخطوات والشروط من واجهة مرئية سهلة.
إمكانيات المنظومة

أهم الركائز المعمارية في Welco

صممت المنصة بمعمارية برمجية حديثة ونظيفة تجمع بين تجربة المستخدم السلسة وأعلى معايير الحوكمة.

No-Code
🛠️

منشئ مسارات العمل المرئي

المدير العام ينشئ الخطوات والأسئلة (نص، اختيار، خيارات متعددة، رفع ملفات) ويضبط شروط الظهور المنطقية (Logic Engine) بدون أي تعديل في الكود البرمجي.

Gemini AI
🤖

مستشار الذكاء الاصطناعي

مدمج عبر REST API مع خوارزمية ذكية لاستخراج الميزات وحفظها كإجابات مباشرة. يعمل بوضع العرض (Mock) عند انقطاع الإنترنت أو بدون مفتاح API.

Enterprise RBAC
🛡️

صلاحيات حازمة وأمان متقدم

جدول صلاحيات صارم بين المدير العام، والمدير، ومدير المشروع، والمطورين، والعملاء. مفاتيح الـ API مشفرة بنظام AES-256-GCM وملفات خاصة ومحمية.

Channels
💬

قنوات محادثة مزدوجة مع إشراف

قناة محادثة خاصة بالفريق الداخلي، وقناة أخرى للعميل. ميزة الإشراف (Moderation) تسمح للأدمن بمراجعة واعتماد ردود المطورين قبل وصولها للعميل.

Realtime & Audit
⚡

تحديثات فورية وسجل تدقيق شامل

اتصال فوري عبر Socket.io للإشعارات والتنبيهات، مع سجل تدقيق غير قابل للتلاعب (Audit Trail) يوثّق كل حركة حساسة في النظام بدقة وبصمة زمنية.

Bilingual & Themes
🌐

ثنائي اللغة بالكامل وواجهة زجاجية

دعم حقيقي ودقيق للغة العربية (RTL) والإنجليزية (LTR)، مع ثيمات فاتحة وداكنة مدروسة جمالياً، وتصميم متجاوب 100% مع شاشات الهواتف والتابلت.

الأسئلة المتكررة

كل ما تريد معرفته عن منظومة Welco

إجابات واضحة عن الأسئلة التقنية والإدارية الأكثر شيوعاً.

كيف أبدأ بتشغيل المشروع محلياً؟ ▼
الأمر بسيط جداً! كل ما تحتاجه هو تنفيذ الأمرين: npm install ثم npm run setup (لإنشاء قاعدة البيانات وتعبئتها ببيانات الحسابات والمشاريع الجاهزة). بعدها اكتب npm run dev وافتح الرابط http://localhost:5173 في متصفحك.
هل الذكاء الاصطناعي إلزامي، وماذا يحدث إذا لم أملك مفتاح API؟ ▼
المنصة تعمل بكفاءة تامة حتى بدون مفتاح API! صممنا نظام مزودي الذكاء الاصطناعي بواجهة (Provider Interface) توفر وضع المحاكاة الذكي (MockProvider) تلقائياً، فيقترح ميزات مناسبة ويعمل دون أي اتصال خارجي. ويمكن للمدير العام إضافة مفتاح Gemini في أي وقت من لوحة التحكم أو ملف .env ليتحول فوراً للوضع الحي.
كيف يستطيع المدير العام تعديل الأسئلة والخطوات بدون كود؟ ▼
من خلال قسم «منشئ مسار الرحلة» (Workflow Builder) داخل لوحة الإدارة؛ يمتلك المدير العام واجهة مرئية كاملة لسحب وإفلات الخطوات، وإضافة الأسئلة وتحديد نوعها، ووضع شروط منطقية (مثل: أظهر هذا السؤال فقط إذا اختار العميل متجر إلكتروني).
كيف تضمن المنصة أمان وسرية ملفات ورسائل العملاء؟ ▼
الملفات المرفوعة لا تُخزن في روابط عامة، بل داخل مجلد تخزين خاص لا يمكن تحميل أي ملف منه إلا عبر فحص أمني للصلاحيات. كما تفصل المنظومة المحادثات الداخلية للفريق عن محادثات العميل، وتوفر ميزة الإشراف (Moderation) لمراجعة رسائل المطورين قبل اعتمادها.
كيف يمكنني رفع هذه الصفحة واستخدامها خارجياً؟ ▼
هذه الصفحة ملف HTML & Vanilla JS & CSS نقي ومستقل بالكامل بدون أي اعتماديات خارجية أو حزم معقدة! يمكنك رفعها على أي استضافة مثل Vercel, Netlify, GitHub Pages، أو ربطها مباشرة مع مشروعك.
